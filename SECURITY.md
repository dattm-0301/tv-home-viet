# Security

Do not post signing keys, passwords, ADB keys, home coordinates, IP/device identifiers, account screenshots, or logs with personal data in public issues. Report a suspected vulnerability privately to the repository owner through GitHub private vulnerability reporting when enabled. No separate monitored security email has been set up yet.

Scope: the Android launcher, theme provider and setup scripts in this repository. Android firmware, third-party apps, network access controls and the external data feeds are separate systems.

Before reporting: reproduce on a disposable emulator when possible and include the app version, Android API and minimal steps with identifiers removed. A source review and automated scan reduce risk; they do not establish that every device or supply-chain dependency is vulnerability-free.

Read [the release review](docs/SECURITY-REVIEW.md), [privacy](PRIVACY.md) and [setup / recovery](docs/SETUP.md).
